Browser Agent 的 Chrome 插件是用户与 AI 对话的前端入口。通过 Side Panel（侧边栏）界面，你可以与 VSCode 后端连接的语言模型进行对话，同时自动感知当前浏览器页面上下文。

## 打开 Side Panel

Side Panel（侧边栏）是 Chrome 插件的主界面。有以下方式打开：

1. **点击工具栏图标** — 在 Chrome 工具栏找到 Browser Agent 的扩展图标，单击即可在浏览器右侧打开 side panel。
2. **固定图标** — 右键点击扩展图标，选择"固定"，方便随时访问。

> 💡 Side Panel 会随浏览器窗口保持打开状态，切换标签页时不会关闭。

## 对话基础

### 发送消息

在底部输入框中输入文字，按 **Enter** 发送。如需换行，使用 **Shift + Enter**。

### 欢迎界面

首次打开或创建新会话时，会显示欢迎界面，提供 4 个快捷提示按钮：

| 按钮 | 功能 |
|------|------|
| 🔍 探索此页面 | 分析当前页面主要内容，给出关键信息摘要 |
| 📝 生成报告 | 根据当前页面内容，生成结构化分析报告 |
| 💡 优化建议 | 分析页面用户体验和内容结构，给出改进建议 |
| 🌐 翻译此页 | 将页面主要内容翻译成中文，保持原文结构 |

点击任意按钮即可直接发送对应提示，开始对话。

### 消息展示

- **用户消息**：右对齐，蓝色背景
- **AI 回复**：左对齐，灰色背景，支持 Markdown 渲染（代码高亮、表格、列表、引用等）
- **代码块**：鼠标悬停时显示复制按钮，一键复制代码
- **时间戳**：每条消息显示相对时间（刚刚、N 分钟前、N 小时前等）

### 消息操作

鼠标悬停在消息上，会出现操作按钮：

- **复制** — 将消息内容复制到剪贴板
- **重新生成**（仅 AI 回复）— 重新发送上一条用户消息获取新的回复

### 停止生成

AI 回复过程中，输入框区域会显示**停止按钮**，点击可随时中断当前生成。

### 历史消息回溯

在输入框为空时，按 **↑**（方向键上）可快速填入上一条用户消息，方便修改后重新发送。

## 模型选择

Side Panel 顶部有一个**模型选择下拉框**，用于切换对话使用的语言模型。

### 使用方法

1. 点击模型选择下拉框
2. 从列表中选择目标模型
3. 后续对话将使用新选择的模型

### 可用模型

模型列表由 VSCode 插件通过 `vscode.lm` API 动态获取，常见的可用模型包括：

- **GPT-4o** (OpenAI)
- **Claude 3.5 Sonnet** (Anthropic)
- 以及其他 VSCode Copilot 支持的模型

> 💡 可用模型取决于你的 VSCode Copilot 订阅和已安装的 LM 提供商扩展。

### 快速切换

除了直接点击下拉框，你还可以使用斜杠命令 `/models` 快速聚焦到模型选择器。

### 注意事项

- 模型选择器在**未连接 VSCode** 或**模型加载中**时会置灰禁用
- 切换模型后，当前会话后续消息将使用新模型回复
- 默认选中列表中的第一个可用模型

## 多会话管理

Browser Agent 支持多会话（conversation）管理，每个会话独立保存聊天记录。

### 会话列表侧边栏

点击 Side Panel 左上角的**菜单按钮**（☰）打开会话列表侧边栏：

- 会话按**最近更新时间**排序，最新的在最前面
- 每个会话条目显示：标题、相对时间、消息数量
- 当前活跃的会话以**蓝色高亮**标记
- 空列表时显示引导文字

### 创建新会话

有三种方式创建新会话：

1. **点击 "+" 按钮** — Side Panel 右上角的加号按钮
2. **斜杠命令** — 在输入框输入 `/new`
3. **快捷键** — `Cmd+Shift+O`（Mac）/ `Ctrl+Shift+O`（Windows/Linux）

### 切换会话

在会话列表侧边栏中，点击目标会话即可切换。切换后侧边栏自动关闭，显示该会话的完整聊天记录。

### 删除会话

- **桌面端**：鼠标悬停在会话条目上，右侧出现删除图标，点击即可删除
- **移动端**：在会话条目上向左滑动超过 60px，出现删除按钮

> ⚠️ 删除当前会话后，系统会自动切换到最近的会话；如果没有其他会话，则创建一个空白会话。

### 会话标题

会话标题**自动生成**，取自第一条用户消息的前 20 个字符。

### 数据持久化

所有会话数据通过 Chrome Storage API 持久化存储：

- 消息自动保存（500ms 防抖延迟）
- 关闭浏览器后重新打开，聊天记录完整保留
- 数据存储在本地，不会上传到任何外部服务器

## 斜杠命令

在输入框中输入 `/` 即可触发斜杠命令菜单。

### 可用命令

| 命令 | 说明 | 效果 |
|------|------|------|
| `/new` | 新建会话 | 创建一个全新的空白会话 |
| `/clear` | 清除当前会话 | 清空当前会话内容，重新开始 |
| `/models` | 切换模型 | 聚焦到模型选择下拉框 |

### 使用方式

1. 在输入框中键入 `/`，命令菜单自动弹出
2. 继续输入可**过滤命令**（如输入 `/n` 过滤出 `/new`）
3. 使用 **↑↓ 方向键**在命令列表中导航
4. 按 **Tab** 自动补全选中的命令名
5. 按 **Enter** 执行选中的命令
6. 按 **Escape** 关闭命令菜单

> 💡 命令匹配不区分大小写，输入 `/NEW` 和 `/new` 效果相同。

## 快捷键

### 全局快捷键

以下快捷键在 Side Panel 打开时随时可用：

| 快捷键 | 功能 |
|--------|------|
| `Cmd+Shift+O`（Mac）/ `Ctrl+Shift+O`（Windows） | 新建会话 |
| `Cmd+L`（Mac）/ `Ctrl+L`（Windows） | 清除当前会话 |

### 输入框快捷键

以下快捷键在输入框获得焦点时可用：

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 发送消息 |
| `Shift+Enter` | 换行（不发送） |
| `↑`（输入框为空时） | 填入上一条用户消息 |
| `Escape` | 关闭斜杠命令菜单 / 清空输入框 |

### 斜杠命令菜单快捷键

命令菜单打开时，以下按键可用：

| 快捷键 | 功能 |
|--------|------|
| `↑` / `↓` | 上下导航命令列表 |
| `Tab` | 自动补全命令名 |
| `Enter` | 执行选中的命令 |
| `Escape` | 关闭命令菜单 |

## 页面上下文感知

Chrome 插件会自动感知当前浏览页面的上下文信息，并随消息一起发送给 AI。

### 感知的信息

- **页面 URL** — 当前标签页的完整地址
- **页面标题** — 当前页面的 document title
- **选中文本** — 你在页面上用鼠标选中的文字

### 上下文指示条

在模型选择器下方，有一条**上下文指示条**：

- 显示当前页面标题
- 如果有选中文本，额外显示"已选中 XXX 字"
- 切换标签页或选中新文本时**实时更新**

### 使用技巧

- **选中页面关键段落后再提问**，AI 会基于选中内容回答，更加精准
- **切换到目标页面**再开始对话，AI 能自动获取页面上下文
- 快捷按钮"探索此页面"和"生成报告"都会自动携带页面上下文

## Agent 模式与工具调用

当 VSCode 后端启用 Agent 模式时，AI 可以自主执行多步操作。

### ReAct 循环步骤

Agent 模式下，AI 的回复会展示三种类型的步骤：

| 图标 | 类型 | 说明 |
|------|------|------|
| 🧠 | Think（思考） | AI 的推理过程，灰色斜体显示 |
| ⚡ | Act（行动） | 调用工具执行操作，显示工具名称和参数 |
| 📋 | Observe（观察） | 工具返回的结果，长内容可折叠 |

### 浏览器操作工具

Agent 可以调用以下浏览器操作工具：

| 工具 | 功能 |
|------|------|
| `click` | 点击页面元素 |
| `type` | 在输入框中输入文字 |
| `scroll` | 滚动页面（到顶部/底部/指定位置） |
| `navigate` | 跳转到指定 URL |
| `screenshot` | 截取当前页面截图 |
| `querySelector` | 查询页面元素信息 |
| `getTextContent` | 获取元素文本内容 |
| `highlight` | 高亮显示页面元素 |
| `waitForElement` | 等待元素出现 |

### 步骤折叠

- 默认只展开最后 3 个步骤，之前的步骤自动折叠
- 点击折叠/展开按钮可查看完整执行过程
- 长观察结果（超过 200 字符）带有"展开全部"按钮

## 连接状态说明

Side Panel 顶部有一个**连接状态指示灯**：

| 状态 | 显示 | 说明 |
|------|------|------|
| 🟢 绿色 | 已连接 | 与 VSCode 插件正常通信 |
| 🔴 红色 | 未连接 | 无法连接到 VSCode 插件 |

### 连接机制

- 通过 WebSocket 连接到 `ws://localhost:7777`（VSCode 插件服务端）
- 断线后每 **3 秒**自动重连
- 需要确保 VSCode 插件已启动且 WebSocket 服务正在运行

## 常见问题

### Side Panel 显示"未连接"怎么办？

1. 确认 VSCode 已打开且 Browser Agent 插件已激活
2. 检查 VSCode 输出面板是否显示 WebSocket 服务已启动（端口 7777）
3. 确认没有其他程序占用 7777 端口
4. 尝试在 VSCode 命令面板执行"Browser Agent: Restart WebSocket Server"

### 模型列表为空？

1. 确认已安装并启用 GitHub Copilot 扩展
2. 确认 Copilot 订阅有效且已登录
3. 等待模型列表加载完成（首次可能需要几秒钟）

### 对话记录丢失了？

会话数据存储在 Chrome 本地存储中，以下操作可能导致数据丢失：

- 清除浏览器数据时勾选了"扩展程序数据"
- 卸载并重新安装了 Chrome 插件
- 使用了浏览器的"重置设置"功能

### AI 回复中断了怎么办？

- 如果是网络波动导致的中断，重新发送消息即可
- 可以使用消息悬停菜单中的**重新生成**按钮重试
- 如果频繁中断，检查 VSCode 端的连接状态和日志
