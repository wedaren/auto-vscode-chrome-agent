# requirements.md — 结构化需求文档

> 本文件由 PM Agent 维护。`program.md` 记录用户原始模糊想法，本文件将其提炼为清晰、可执行的需求条目。

---

## 产品定位

Chrome 插件 + VSCode 插件的 AI Agent 系统。用户在 Chrome Side Panel 对话，VSCode 作为 Agent 大脑，实现浏览器上下文感知、智能对话和自动化浏览器操作。

---
